# Portfólio — Lucas Barros da Silva

Portfólio pessoal estático criado com HTML, CSS e JavaScript nativo.

## Estrutura

- `index.html` — conteúdo e navegação do site.
- `index.css` — estilos e layout responsivo.
- `assets/foto-perfil.png` — foto usada no início e na seção Sobre.

## Como visualizar

Abra `index.html` em um navegador. O site não exige instalação nem etapa de build. A fonte Inter é carregada do Google Fonts quando há conexão com a internet.

## Observações

O repositório público do projeto Pokédex está vinculado à seção de projetos. Os outros cards aparecem sem link enquanto os endereços dos respectivos repositórios não forem informados.
